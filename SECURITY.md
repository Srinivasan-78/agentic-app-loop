# Security Policy

## Supported Versions

Security updates are applied to the latest release and the default branch of `Srinivasan-78/pennywright`.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

- Use GitHub Private Vulnerability Reporting on `https://github.com/Srinivasan-78/pennywright/security/advisories/new`, or
- Contact the maintainer directly via the email listed on their GitHub profile.

Please include reproduction steps, affected versions/commits, and potential impact. We aim to acknowledge reports within 72 hours.
